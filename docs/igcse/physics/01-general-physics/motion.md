# Motion

## What is Motion?

Motion occurs when an object changes its position with time.

---

## Distance and Displacement

| Quantity     | Meaning                                     |
| ------------ | ------------------------------------------- |
| Distance     | Total path travelled                        |
| Displacement | Straight-line distance from start to finish |

---

## Speed

Speed is defined as:

Speed = Distance ÷ Time

### Example

A car travels 120 km in 2 hours.

Speed = 120 ÷ 2 = **60 km/h**

---

## Key Exam Tips

• Always include units  
• Distinguish between scalar and vector quantities
